# Inter Doubt — Side Agent

A browser side panel that sits next to Claude. Ask a quick doubt about
whatever is currently in your main chat, get an answer in the side panel,
close it — your main chat is exactly where you left it. No scrolling back
through the conversation to re-orient yourself.

## How it works

- **Content script** (`content.js`) reads the visible conversation on the
  current tab (claude.ai, with basic support for chatgpt.com and
  gemini.google.com too) — read-only, it never modifies the page.
- **Side panel** (`sidepanel/`) is a separate Chrome side panel UI with its
  own scratch conversation. It captures the page's context on open, and you
  can hit **Refresh** to re-capture as the main chat grows.
- Select text on the page and right-click → **"Ask side agent about
  ..."** to jump straight into the side panel with that text quoted.
- Answers are generated by calling your chosen provider's API directly from
  your browser using your own API key (stored only in local extension
  storage). **Anthropic (Claude)**, **OpenAI (ChatGPT)**, **xAI (Grok)**,
  and **Google (Gemini)** are all supported — pick one in Settings and the
  model field offers suggestions for that provider (or type any model id
  yourself). Provider config and API calls live in `providers.js`, shared
  by the side panel and the settings page.

Because it's a side panel rather than a new tab or an injected overlay, your
main chat's scroll position and state are never touched — closing the panel
just closes it.

## Install (unpacked, for development/personal use)

1. Open `chrome://extensions`.
2. Enable **Developer mode** (top right).
3. Click **Load unpacked** and select this folder.
4. Click the extension icon → it opens the side panel. Click the gear icon
   in the panel, pick a **Provider**, and paste in that provider's API key:
   - Anthropic: [console.anthropic.com](https://console.anthropic.com)
   - OpenAI: [platform.openai.com/api-keys](https://platform.openai.com/api-keys)
   - xAI: [console.x.ai](https://console.x.ai)
   - Gemini: [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
5. Open a chat on claude.ai, click the extension icon to open the side
   panel, and start asking doubts.

## Notes / limitations

- The DOM selectors used to read claude.ai's conversation are best-effort
  and may need updating if Claude changes its page structure; there's a
  generic fallback that just grabs the visible page text if the specific
  selectors don't match anything.
- The API key is used for a direct browser call to that provider's API
  only (`api.anthropic.com`, `api.openai.com`, `api.x.ai`, or
  `generativelanguage.googleapis.com`). It never leaves your machine except
  in that one request.
- Captured context is capped at ~24k characters (most recent turns kept)
  to stay within model context limits.
